# PRODUCTION

Put **packaging, dielines, labels and product graphics** in this folder and the site picks them up.

To add work from a browser: open this folder on GitHub, press
**Add file → Upload files**, drag the files in, and commit. A few minutes
later the pieces are on the site — see [../README.md](../README.md) for what
happens in between and what to do about the name it gives them.

Anything directly in this folder is filed under **PRODUCTION**. Folders inside this
one are ignored, so a `_old` or a `working` folder is safe to keep here.
